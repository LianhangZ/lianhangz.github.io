# Prepare for Research Source Code of `type_traits`

# Knowledge about `type_traits` in **C++ Standard Library**

| Structure | `type_traits` library consists of `type_traits.h` and `type_traits/`, which is a folder including `.h` files declaring type traits, such as `integral_constant.h` declaring `integral_constant`, `is_const.h` declaring `is_const` and so on.

| Recommand | Almost every type trait depends on one another, so I recommand starting with `integral_constant`, because this type traits does not need to reference any other type trait.

| Recommand | To distinguish `std::integral_constant` and your own `integral_constant`, I recommand using `namespace`. For my own re-implementation, I name a namespace as `stl` so that I can call my own `integral_constant` through `stl::integral_constant` rather than that in Standard Library (`std::integral_constant`).
